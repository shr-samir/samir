# Docs

Three layers, from general to specific. Open the one that matches your question.

| Question | Read |
|---|---|
| How does the web actually work, without frameworks? | [`fundamentals.md`](fundamentals.md): platform concepts that hold for every feature |
| What is this feature doing, and why? | [`features/<ID>-….md`](features/): start with **Understanding** (TL;DR, essence per layer, questions and answers), then **How it works** for the file-by-file walkthrough |
| What surprised us while building? | [`learnings.md`](learnings.md): one- or two-line gotchas, tagged by feature |
| What is the whole project, and what's in scope? | [`PRD.md`](PRD.md): scope, decisions, feature list |

**Reading order when you're new to the codebase:** fundamentals TL;DR → the
current feature's Understanding section → How it works.
